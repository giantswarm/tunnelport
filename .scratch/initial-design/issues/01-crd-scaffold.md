# CRD scaffold + `RemoteApp` type

Status: ready-for-agent
Type: AFK

## What to build

kubebuilder-style project scaffold with the `RemoteApp` Go types in
group `access.giantswarm.io/v1alpha1`. CRD generation wired into `make`
so `make manifests` produces a valid CRD YAML. OpenAPI validation rules
on the spec fields. No reconciliation logic yet — just the type
definitions and the build infrastructure.

The spec carries `appName`, `port`, `proxyAddr`, `tokenRef.{name,key}`,
and an optional `replicas`. The status carries `ready`, `lastError`,
`observedGeneration`, and a standard `conditions` list. See
`CONTEXT.md` for the resolved field semantics.

- [ ] `go build ./...` succeeds; `make manifests` produces a CRD YAML
- [ ] `kubectl apply` of a sample valid `RemoteApp` is accepted

- [ ] CRD has `OwnerReferences`-friendly metadata (kind/name/uid lookups)
- [ ] Sample CR YAML committed under `config/samples/`
